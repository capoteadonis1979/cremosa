# CREMOSA

App Android de cremes de cabelo (v0.1): diagnóstico do cabelo, estante de cremes com foto e preço, mercado de troca/venda e onde comprar com mapa e comparação de preços.

Descarregar a última APK: https://github.com/capoteadonis1979/cremosa/releases/latest/download/Cremosa-0.1.apk

- `web/src.html` — código da app (web). `python3 web/build.py` gera `web/index.html` (com Leaflet e letras incluídas), que se copia para `app/src/main/assets/`.
- A APK compila-se sozinha no GitHub Actions a cada push.
